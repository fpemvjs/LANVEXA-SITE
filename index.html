02 / PASSIVE NEIGHBOR DISCOVERY

Use what the network advertises.

LANVEXA listens locally for LLDP and CDP advertisements. It does not log in to the switch or use SNMP credentials for the current neighbor-discovery workflow.

No advertisement is also an honest result. It does not mean the switch is down. LLDP/CDP may be disabled, filtered, delayed, or not advertised toward the endpoint.

05 / CURRENT PROTOTYPE

Built on standard Windows and network components.

The current application is a Windows prototype built with .NET 8 and WPF. Npcap and SharpPcap support passive LLDP/CDP capture. Gateway, DNS, and configured TCP checks are active network tests.

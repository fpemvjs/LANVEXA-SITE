02 / OBSERVED

Build the record from active checks and passive observations.

See what passed, what failed, and what the network advertised. LANVEXA listens locally for LLDP and CDP advertisements without logging in to the switch or using SNMP credentials for the current neighbor-discovery workflow.

No advertisement is also an honest result. It does not mean the switch is down. LLDP/CDP may be disabled, filtered, delayed, or not advertised toward the endpoint.

03 / INTERPRETED

NEXT ACTION

Continue locally or escalate with a consistent set of observations. Relay the selected adapter, completed checks, unresolved checks, and advertised neighbor or Port ID when observed.LANVEXA does not claim a root cause or present report export as a current capability.

A failed configured check can narrow the next investigation. A check marked not tested remains unresolved. Neighbor information can be relayed when advertised; when it is not detected, connectivity must be judged from the connectivity checks rather than the missing advertisement.

Triage is rarely a single happy path. Test LinkLens against 6 realistic network conditions—from active address and route timeouts to passive neighbor absences and scope boundaries.

01
Deterministic Failure Stoppage

When DHCP or gateway route fails, dependent checks halt immediately rather than producing misleading downstream errors.

02
Independent Passive Capture

Switch discovery runs asynchronously via LLDP/CDP frames, remaining decoupled from IP and reachability test states.

03
Strict Scope Boundaries

Clear classification when an issue—such as physical-layer cabling or PoE power—requires dedicated hardware instrumentation.

SCN-03 ROUTE TIMEOUT

Gateway Unreachable

IP assigned, but default gateway does not respond to ICMP traversal. Downstream resolution halted.

SCN-04 RESOLUTION DROP

DNS Resolution Failure

Gateway reachable, but DNS queries time out. Highlights name resolution as distinct from IP routing.

SCN-05 NEIGHBOR ABSENT

No LLDP / CDP Advertisement

All connectivity checks pass, but no broadcast advertisement is detected. Evaluates network context without inferring fault.

SCN-06 OUTSIDE SCOPE

PoE Limitation Boundary

Illustrates boundary discipline: flags that physical power delivery requires a hardware tester rather than software guesswork.

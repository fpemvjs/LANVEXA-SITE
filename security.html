ENGINEERING DISCLOSURE / PRE-RELEASE

Security information

What is known about the current prototype, followed by what must still be verified against the application source and release package.

KNOWN

LANVEXA is a Windows .NET 8/WPF prototype. It uses Npcap and SharpPcap for LLDP/CDP neighbor discovery and performs active gateway, DNS, and configured TCP connectivity checks.

Current architecture

PLATFORM
Windows · .NET 8 · WPF
PACKET-CAPTURE COMPONENTS
Npcap · SharpPcap
PASSIVE INPUT
LLDP/CDP advertisements
ACTIVE CHECKS
Gateway, DNS, configured TCP/443

Packet capture

The prototype uses packet capture to receive LLDP/CDP advertisements on a wired interface. These frames can contain system name, port identifier, chassis information, description, and management information when the neighboring device advertises those fields.

Under verification: the exact capture filter, in-memory packet lifecycle, and whether any captured bytes are written to local storage.

Active connectivity checks

Gateway reachability, DNS resolution, and a configured TCP/443 connection are active tests: they generate network traffic. The final public test destination and configuration behavior have not yet been documented.

Local data handling

No public guarantee about telemetry, crash reporting, diagnostic logs, local retention, or uploaded diagnostic data is made yet. These behaviors must be verified from the product source and release configuration.

Permissions

LANVEXA currently requires a compatible packet-capture environment for LLDP/CDP discovery. Packaging and distribution requirements are being finalized for beta. Npcap installation and capture permissions depend on packaging and Npcap configuration. LANVEXA does not yet publish an administrator-rights or silent-deployment claim.

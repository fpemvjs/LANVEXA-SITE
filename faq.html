PRODUCT QUESTIONS

Clear answers before installation.

Current capabilities, deliberate limitations, and release details that are still being validated.

Does LANVEXA replace a cable tester?

No. LANVEXA performs logical connectivity checks and passive neighbor discovery from a Windows laptop. It does not provide continuity, wiremap, cable length, TDR fault location, PoE load testing, cable qualification, or SFP optical measurements. Dedicated hardware remains appropriate for those tasks.

What happens if LLDP/CDP is not advertised?

LANVEXA can still report interface, link, addressing, gateway, DNS, and configured TCP results. Neighbor fields remain not detected. A missing advertisement is not labeled as a connectivity failure and does not mean the switch is down.

Does LANVEXA log in to the switch?

No for the current passive neighbor-discovery workflow. LANVEXA listens for LLDP/CDP advertisements received on the selected wired interface.

Does neighbor discovery require SNMP credentials?

No. Current LLDP/CDP neighbor discovery does not use SNMP polling or SNMP credentials.

Why does LANVEXA use Npcap?

The Windows prototype uses Npcap with SharpPcap to receive LLDP/CDP advertisements. Exact packaging, licensing, installation, and runtime privilege requirements remain under verification and are documented on the Security page.

Which Windows versions are supported?

A public compatibility matrix has not yet been verified. Windows version, architecture, .NET packaging, adapter, and Npcap compatibility testing must be completed before public beta distribution.

Can I use LANVEXA instead of PowerShell?

LANVEXA does not make the underlying checks proprietary or replace engineering tools. Its purpose is to run a consistent first pass and keep link, addressing, connectivity, and neighbor observations together in one result.

How is LANVEXA different from Wireshark or an LLDP/CDP utility?

Wireshark is built for deep packet inspection, and focused discovery utilities can be useful when neighbor information is the only objective. LANVEXA is intended for a narrower technician workflow: basic connectivity checks and passive LLDP/CDP observation presented together without requiring packet-analysis expertise. These tools remain appropriate when deeper or more specialized investigation is required.

Can LANVEXA export a report?

Report export is not presented as a current capability. The website shows the structured information available together on screen.

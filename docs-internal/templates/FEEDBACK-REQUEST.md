# Post-use feedback request draft

Subject: What did LANVEXA change on the ticket?

If you used LANVEXA on a real Ethernet issue, the most useful feedback is what happened next:

- Could it be installed and run?
- Did it confirm basic connectivity, expose a DNS/gateway issue, or identify advertised switch/port data?
- Did its result change your next troubleshooting action?
- Did you relay the result to someone else?
- Did you still need another tool, and why?
- Was any result unclear, missing, or misleading?
- Would you voluntarily use it on another ticket?

Please sanitize screenshots. Do not send packet captures, credentials, private hostnames, public IPs, ticket data, or personal information unless specifically requested through an approved secure process.

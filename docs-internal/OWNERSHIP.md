# Operational ownership

All roles are **UNASSIGNED**. Controlled beta cannot cross the operations gate until the required roles have named owners and backups where appropriate.

| Role | Responsibilities | Status |
|---|---|---|
| PRODUCT OWNER | Eligibility, product scope, beta acceptance, stop/go decision | UNASSIGNED |
| WEB OWNER | Source, build, metadata, deploy verification, rollback | UNASSIGNED |
| BETA OPERATIONS OWNER | Request review, records, tester communication, deletion | UNASSIGNED |
| SECURITY CONTACT | Reports, triage, disclosure, release-security gates | UNASSIGNED |
| PRIVACY CONTACT | Notice, retention, deletion, access decisions | UNASSIGNED |
| RELEASE OWNER | Installer identity, integrity artifacts, distribution, revocation | UNASSIGNED |

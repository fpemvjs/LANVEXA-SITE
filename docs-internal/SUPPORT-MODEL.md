# Controlled-beta support model

Use one assigned, dedicated support email alias with an owner and backup. A lightweight structured issue template may be added after an actual support channel exists; do not build a portal.

Request only what is needed: LANVEXA version/release identifier, Windows version, Ethernet adapter, compatible packet-capture environment/Npcap state and version when relevant, displayed result state, reproduction steps, and an explicitly sanitized screenshot. Do not request packet captures by default. Never request credentials, switch configuration, private ticket content, or security-tool bypasses.

Define acknowledgement/escalation expectations, security routing, deletion/retention, supported beta scope, and stop-distribution authority before invitations are sent.

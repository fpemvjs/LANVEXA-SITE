# Controlled-beta success criteria

Do not set percentages before a baseline exists. Observe:

- **INSTALLATION:** can selected testers install successfully without unsafe workarounds?
- **EXECUTION:** can they complete a first-pass diagnostic?
- **DISCOVERY:** when advertisements exist, is useful neighbor data surfaced accurately?
- **FAILURE HANDLING:** are partial/not-detected states understood?
- **ACTIONABILITY:** did the result change the next troubleshooting action?
- **ESCALATION:** did it improve handoff quality?
- **REUSE:** do testers voluntarily use it again?
- **TRUST:** do installation/security concerns prevent adoption?

After the first cohort, establish targets from observed baseline and record denominators, environment, and failure categories. A signup is not product validation.

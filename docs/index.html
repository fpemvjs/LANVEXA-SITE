GETTING STARTED / PRE-RELEASE

Getting started with LANVEXA

LANVEXA is currently a Windows prototype for first-pass Ethernet diagnostics. Public installation steps cannot be finalized until the release package and Npcap deployment model are verified.

WHAT THE CURRENT PROTOTYPE DOES

Detects a wired interface, reports addressing state, tests gateway/DNS/configured TCP connectivity, and listens for LLDP/CDP neighbor advertisements.

Expected technician workflow

  1. Connect the Windows laptop to the Ethernet jack.
  2. Open LANVEXA and select or confirm the wired interface.
  3. Allow the configured connectivity checks to complete.
  4. Allow time for an LLDP/CDP advertisement to arrive.
  5. Read the combined result, including any failed, not-tested, or not-detected state.

Installation status

The prototype architecture uses Npcap and SharpPcap for neighbor discovery. The final installer, Windows compatibility matrix, Npcap packaging, required privileges, signing, and enterprise deployment guidance remain under verification.

Do not treat this page as final installation documentation. It is the documentation foundation for the controlled beta package.

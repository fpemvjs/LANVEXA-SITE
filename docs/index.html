GETTING STARTED / PRE-RELEASE

Getting started with LANVEXA

LANVEXA is currently a Windows prototype for first-pass Ethernet diagnostics. Public installation steps cannot be finalized until the release package and Npcap deployment model are verified.

WHAT THE CURRENT PROTOTYPE DOES

Detects a wired interface, reports addressing state, tests gateway/DNS/configured TCP connectivity, and listens for LLDP/CDP neighbor advertisements.

Expected technician workflow

  1. Connect the Windows laptop to the Ethernet jack.
  2. Open LANVEXA and select or confirm the wired interface.
  3. Allow the configured connectivity checks to complete.
  4. Allow time for an LLDP/CDP advertisement to arrive.
  5. Read the combined result, including any failed, not-tested, or not-detected state.
  6. Use the observations to continue locally or escalate with clearer evidence.

What is known

Current development information describes a Windows desktop prototype that uses Npcap and SharpPcap for passive neighbor discovery. The public website does not distribute the application or Npcap.

What is not yet verified for controlled beta

  • Supported Windows versions and processor architectures
  • Runtime prerequisites and administrator requirements
  • Installer, upgrade, and uninstall behavior
  • Npcap prerequisite and packaging details
  • Signing, publisher identity, and release version

Installation status

Controlled-beta installation instructions are not yet published. Selected testers will receive verified installation and distribution information before installing anything. Requesting access is not an automatic download or acceptance into the beta.

Real product media slot

No authentic application media is installed in the website repository. When supplied, use public/media/lanvexa-demo.webm, public/media/lanvexa-demo.mp4, and public/media/lanvexa-demo-poster.png.

NEIGHBOR DISCOVERY

LLDP/CDP discovery on Windows

LANVEXA listens for link-layer advertisements received on the selected wired interface. It reports what the neighboring device sends; it does not infer unadvertised switch data.

Protocols

LLDP is defined by IEEE 802.1AB. CDP is Cisco Discovery Protocol. Managed switches and other network devices can periodically advertise identity and interface information using these protocols.

Fields LANVEXA may observe

  • System or switch name
  • Port identifier or interface name
  • Chassis identifier
  • System description
  • Management information

Availability and representation vary by device, configuration, vendor, protocol, and advertised TLVs. An advertised port identifier is not guaranteed to be a normalized physical-interface name.

No switch credentials

The current discovery workflow does not log in to the switch, poll SNMP, or make configuration changes. It listens for received advertisements.

Important limitation

ADVERTISEMENT REQUIRED

LANVEXA can show only neighbor information it observes. LLDP/CDP may be disabled, filtered, delayed, sent infrequently, or omitted toward endpoint-facing ports.

Missing data is not switch failure

No advertisement observed means exactly that. It does not prove the switch is unavailable, that the port is misconfigured, or that Ethernet connectivity has failed.

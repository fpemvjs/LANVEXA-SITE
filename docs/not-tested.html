PRODUCT SCOPE

What LANVEXA does not test

LANVEXA is software running on a Windows computer. It does not contain the measurement hardware required for cable qualification or advanced physical-layer testing.

Not current LANVEXA capabilities

  • Cable continuity or wiremap
  • Cable length measurement
  • TDR fault distance or fault location
  • Cable certification or qualification
  • PoE voltage or load testing
  • SFP optical power measurements
  • Advanced physical-layer error testing
  • Wi-Fi analysis
  • SNMP polling
  • Switch configuration or SSH automation

Negotiated link speed is not cable qualification

A Windows-reported negotiated link such as 1.0 Gbps describes the current NIC link state. It does not certify that the installed cable meets a cabling standard or will operate without physical errors under load.

When to use dedicated hardware

Use a purpose-built tester when the ticket requires wiremap, cable length, fault location, PoE loading, optical measurements, certification, or deeper physical-layer validation.

Where LANVEXA fits

LANVEXA targets first-pass logical connectivity and neighbor-identification questions from the laptop already used onsite.
